# Changelog

## 0.1.0 — prepared for the first public release

- Append-only plain-text streaming with stable word nodes and spatial reflow.
- Keyed DOM layout motion for an existing renderer.
- Batched response views with separate text, code and image renderers.
- ESM exports, TypeScript declarations and typed built-in event payloads.
- Reduced-motion handling, cleanup and configurable measurement limits.

This entry records the release contents. Registry publication is a separate manual step.
